Which model does the detector use?

Four models were tuned with the same budget (25 random configurations, 5-fold cross-validation, class-imbalance handling). The winner is chosen on the validation set; the test set is scored once, afterwards, to report the final number.

    Honest limitations

    Known issues found during testing

    Diagnosed on this project's dataset; fixes are the next milestone.

    Rank bias. 66% of training URLs ranked in the Tranco top 1000 are phishing, because phishing hosted on vercel.app, pages.dev, blogspot or weebly inherits the platform's rank. Famous sites sit in the same rank zone.
    “www.” quirk. No legitimate bare-root URL in the training data starts with “www.”, and “www” counts as a subdomain. Six famous sites flagged at 65–99% with “www.” drop to 1–7% without it (e.g. youtube.com 1.6%).
    Dependence on the Tranco list. If the list fails to load, legitimate false alarms rise from 0.4% to 85% in simulation, so the checker shows the list's status.
    Split honesty. Grouping cross-validation by domain gives F1 0.966 (random split: 0.988), consistent with the reported test F1.
